# 🚗 Python Automations – License Plate Annotation Workflows

This folder contains Python scripts for automating license plate annotation workflows, including data preprocessing, image extraction, and human-in-the-loop verification.

---

## 📌 Project Overview

These scripts were developed to automate the process of preparing license plate datasets for Machine Learning pipelines.  
The workflow ensures:

✅ Only relevant records are processed  
✅ Images are extracted into a structured folder system  
✅ Manual verification is fast and reliable for high-quality annotations  

---

## 📂 Scripts Included

### 🟢 1. generate_char_state_txt.py
- Reads Excel / CSV files containing plate data  
- Filters rows where “which is right” = "Plate Recognizer"  
- Dynamically detects plate number and image filename columns  
- Generates a structured output file in the format:

<main_folder>/<image_name>.jpg <plate_number> <state_code>

- Prepares clean data for downstream automation or ML training  

---

### 🟡 2. images.py
- Reads the text file generated by generate_char_state_txt.py  
- Copies only required images from source to centralized destination folder  
- Prints warnings for missing images  
- Ensures correct dataset preparation for verification or model training  

---

### 🔵 3. manualverification.py
- Provides a GUI-based manual verification tool using OpenCV  
- Displays images with overlay: image name and plate number  

Keyboard Controls:
- Enter → Mark as VERIFIED  
- X → Add COMMENT  
- S → Skip image  
- Esc → Exit early  

- Saves all verification results to a text file  
- Implements human-in-the-loop quality control for ML datasets  

---

## 🛠️ Tools & Libraries Used

- Python 3.x  
- Pandas – Data processing & filtering  
- OpenCV – Image display & GUI verification

## ⚙️ Setup Instructions

### 1. Clone the Repository
git clone https://github.com/trexaki/my-projects.git  
cd my-projects/python-automations  

### 2. Install Dependencies
pip install pandas opencv-python  

### 3. Prepare Input Data
- Place Excel/CSV files anywhere on your system  
- Place original images in the source images folder  

### 4. Run Scripts in Order
python generate_char_state_txt.py  
python images.py  
python manualverification.py
